
# Machine Learning-Enabled Smart Transit: Real-Time Bus Tracking System for Enhanced Urban Mobility

## Overview

This project develops a Machine Learning-based Smart Transit System to predict real-time bus arrival times using transportation data such as GPS location, route information, traffic conditions, and weather conditions.

## Objectives

* Predict bus arrival times accurately.
* Reduce passenger waiting time.
* Improve public transportation efficiency.
* Analyze the impact of traffic and weather on transit operations.

## Dataset Features

* Bus_ID
* Route
* Latitude
* Longitude
* Traffic
* Weather
* Arrival_Time

## Technology Stack

* Python
* Pandas
* NumPy
* Scikit-Learn
* Flask
* HTML, CSS, JavaScript

## Project Workflow

Dataset → Data Processing → Machine Learning Model → Arrival Time Prediction → User Interface
